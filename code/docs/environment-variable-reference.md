# Environment Variable Reference

Complete reference for all environment variables used across the Runtime container, Lambda functions, and frontend SPA.

## Runtime Container Variables

Set by CDK in the Runtime construct (`cdk/stack.ts`, lines 430–445). Available inside the agent Docker container.

| Variable | Required | Default | Purpose | Consumed By |
|----------|----------|---------|---------|-------------|
| `GATEWAY_MCP_URL` | Yes | — | AgentCore Gateway MCP endpoint URL | `main_ws.py` → `MCPClient` |
| `GATEWAY_CLIENT_ID` | Yes | — | Cognito app client ID for OAuth | `tools/oauth_provider.py` |
| `GATEWAY_CLIENT_SECRET_ARN` | Yes | — | Secrets Manager ARN for the Cognito client secret | `tools/oauth_provider.py` |
| `GATEWAY_TOKEN_ENDPOINT` | Yes | — | Cognito OAuth2 token endpoint URL | `tools/oauth_provider.py` |
| `GATEWAY_SCOPE` | Yes | `agentcore/gateway` | OAuth scope for Gateway access | `tools/oauth_provider.py` |
| `AGENTCORE_MEMORY_ID` | No | — | AgentCore Memory resource ID. If unset, runs without Memory (graceful degradation). | `main_ws.py` → `_create_session_manager` |
| `BEDROCK_MODEL_ID` | Yes | `us.anthropic.claude-sonnet-4-20250514-v1:0` | Bedrock foundation model identifier | `config/model.py` → `create_model` |
| `SYSTEM_PROMPT_BUCKET` | Yes | — | S3 bucket name for system prompt files | Agent startup (prompt loading) |
| `SYSTEM_PROMPT_PREFIX` | Yes | `runtime-strands_agent-systemprompts` | S3 key prefix for system prompt files | Agent startup (prompt loading) |
| `AWS_REGION` | Yes | `us-west-2` | AWS region for all service calls | `config/model.py`, `tools/oauth_provider.py`, `main_ws.py` |

## Test User Provisioner Lambda Variables

Set by CDK in the auth construct (`cdk/lib/aidlc-platform-auth.ts`) on the consolidated test-user provisioner (`cdk/custom-resources/provision_test_users.py`).

| Variable | Required | Default | Purpose | Consumed By |
|----------|----------|---------|---------|-------------|
| `USER_POOL_ID` | Yes | — | Cognito User Pool ID the test users are provisioned into | `provision_test_users.py` |
| `TEST_USERS` | Yes | — | JSON array of `{email, password, group, role}` for every pre-provisioned test user (BA, SA, Maintenance Specialist, developer) | `provision_test_users.py` |

## Frontend Variables (Local Development)

Set in `code/ui-frontend/.env` for local development with `vite dev`. In production, these are replaced by `config.json` generated by CDK.

| Variable | Required | Purpose | Consumed By |
|----------|----------|---------|-------------|
| `VITE_COGNITO_USER_POOL_ID` | Yes | Cognito User Pool ID | `app/lib/config.ts` |
| `VITE_COGNITO_CLIENT_ID` | Yes | Cognito PKCE client ID (not the machine-to-machine client) | `app/lib/config.ts` |
| `VITE_COGNITO_DOMAIN` | Yes | Cognito hosted domain (e.g., `xxx.auth.us-west-2.amazoncognito.com`) | `app/lib/config.ts` |
| `VITE_AWS_REGION` | Yes | AWS region | `app/lib/config.ts` |
| `VITE_RUNTIME_ARN` | Yes | AgentCore Runtime ARN | `app/lib/config.ts` |
| `VITE_FILES_BUCKET` | Yes | S3 bucket name (used for display, not direct access) | `app/lib/config.ts` |

## Production Frontend Config (`config.json`)

Generated by CDK at deploy time (`cdk/stack.ts`, lines 590–600) and deployed to S3 under the `/web` prefix. The SPA loads this at startup before falling back to `VITE_*` env vars.

```json
{
  "cognitoUserPoolId": "us-west-2_XXXXXXX",
  "cognitoClientId": "xxxxxxxxxxxxxxxxxxxxxxxxxx",
  "cognitoDomain": "xxx.auth.us-west-2.amazoncognito.com",
  "awsRegion": "us-west-2",
  "runtimeArn": "arn:aws:bedrock-agentcore:us-west-2:123456789012:runtime/strands_agent-XXXXXXXX",
  "filesBucket": "agentcore-files-123456789012-us-west-2"
}
```

## SSM Parameter Store Values

Stored under the `/agentcore/` prefix (configurable via `config.parameterStorePrefix`). Retrieve all values with:

```bash
bash scripts/get-params.sh
```

| Parameter Path | Value Source | Purpose |
|---------------|-------------|---------|
| `/agentcore/bedrock/model-id` | `config.runtime.bedrockModelId` | Bedrock model identifier |
| `/agentcore/cognito/user-pool-id` | CDK output | Cognito User Pool ID |
| `/agentcore/cognito/client-id` | CDK output | Cognito app client ID (client credentials) |
| `/agentcore/cognito/pkce-client-id` | CDK output | Cognito PKCE client ID (browser auth) |
| `/agentcore/cognito/token-endpoint` | CDK computed | OAuth2 token endpoint URL |
| `/agentcore/memory/id` | CDK output | AgentCore Memory resource ID |
| `/agentcore/gateway/endpoint` | CDK output | Gateway MCP endpoint URL |
| `/agentcore/gateway/scope` | Hardcoded | `agentcore/gateway` |
| `/agentcore/runtime/arn` | CDK output | AgentCore Runtime ARN |
| `/agentcore/cloudfront/domain` | CDK output | CloudFront distribution domain |

## Secrets Manager Entries

| Secret Name | Purpose | Accessed By |
|-------------|---------|-------------|
| `/agentcore/secrets/cognito-client-secret` | Cognito app client secret for OAuth client credentials flow | Runtime container via `GATEWAY_CLIENT_SECRET_ARN` |

Retrieve the secret value:

```bash
aws secretsmanager get-secret-value \
  --secret-id /agentcore/secrets/cognito-client-secret \
  --query SecretString --output text
```

## Populating `.env` for Local Development

After deploying the stack, populate the frontend `.env` file:

```bash
# Get SSM parameters
bash scripts/get-params.sh

# Get CloudFormation outputs
aws cloudformation describe-stacks --stack-name AgentCoreStrandsStack \
  --query "Stacks[0].Outputs" --output table
```

Then create `code/ui-frontend/.env`:

```bash
VITE_COGNITO_USER_POOL_ID=<cognito/user-pool-id from SSM>
VITE_COGNITO_CLIENT_ID=<cognito/pkce-client-id from SSM>
VITE_COGNITO_DOMAIN=<derived from cognito/token-endpoint, strip https:// and /oauth2/token>
VITE_AWS_REGION=us-west-2
VITE_RUNTIME_ARN=<runtime/arn from SSM>
VITE_FILES_BUCKET=<S3BucketName from CloudFormation outputs>
```

For the Runtime container local development, see `docs/local-development.md` for the full set of `export` commands.
